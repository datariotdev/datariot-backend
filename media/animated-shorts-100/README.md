# Datariot — Pip & Mochi: 100 Animated Shorts

100 original educational animated stories. Each has a separate English script, synchronised synthetic English narration, captions, original vector character animation, and a portrait cover. Produced for Datariot, November 21, 2026.

Format: H.264 MP4, 720 × 1280, 20 fps, AAC mono narration. Each story contains four narrated beats. No third-party footage or impersonated creator uploads. Editorial attribution: Datariot Editorial. AI-assisted writing and procedural animation; these are not diffusion-model-generated video clips.

media/001.jpg … media/100.jpg — individual cover images.
